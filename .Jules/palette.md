## 2025-05-15 - [Consistency in Static Sites]
**Learning:** In projects with multiple static HTML files instead of components, accessibility improvements (like skip links and ARIA attributes) must be applied across all files to maintain a cohesive UX, even if it exceeds standard line-count guidelines.
**Action:** Use batch processing tools like 'sed' or 'grep' to ensure site-wide consistency for fundamental UX/a11y patterns.
