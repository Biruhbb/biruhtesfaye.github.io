## 2026-08-09 - Solving Scroll-Animated Focus Traps and Mobile Nav Accessibility
**Learning:** Elements animated with `opacity: 0` and `transform: translateY(...)` using `IntersectionObserver` remain in the DOM and are tab-focusable. If focused by a keyboard-only user before scrolling to them, they create "invisible focus traps" where the outline is active but hidden. Adding a dynamic `focusin` listener ensures they instantly become fully visible (`opacity: 1`, `transform: translateY(0)`) when they or their descendants receive keyboard focus. Additionally, mobile navigation toggles require synchronization of the `aria-expanded` state and an Escape key keydown listener that restores focus to the toggle button.
**Action:** Always combine scroll-based animations with focusin event handlers to bypass invisible focus traps, and guarantee that mobile drop-downs support Escape and restore focus back to the menu toggle.
