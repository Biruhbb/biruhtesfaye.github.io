## 2026-06-20 - Dark Theme Keyboard Focus and Accessible Mobile Navigation
**Learning:** Dark theme minimalist portfolios often rely on browser-default focus outlines which are virtually invisible against dark backgrounds (e.g. `--bg: #111111`). For true keyboard accessibility, focus indicators must be explicitly styled using high-contrast brand variables without disrupting the clean aesthetic. Additionally, mobile toggle buttons that only style class toggling ignore screen reader users if standard attributes like `aria-expanded` and keyboard overrides like the `Escape` key are not managed.
**Action:** Always pair mobile menu visibility with dynamic `aria-expanded` and `aria-controls` states, add support for closing menus with the `Escape` key, and explicitly define `:focus-visible` styles using theme colors like `--accent` with a clean `outline-offset` to respect design minimalism.
