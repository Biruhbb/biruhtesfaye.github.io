## 2026-06-20 - Dark Theme Keyboard Focus Indicators & Mobile Menu Accessibility
**Learning:** In highly customized dark-themed portfolios, default browser focus rings are often invisible or high-contrast styles break the visual theme. Providing customized `:focus-visible` styles using theme accent variables ensures both AAA accessibility and visual cohesiveness. Furthermore, mobile hamburger toggles must announce their open/close state (`aria-expanded`) and support keyboard-friendly dismiss actions (e.g., the Escape key) to prevent trapping keyboard-only/screen-reader users inside mobile navigation drawers.
**Action:** Always verify focus rings visually on both dark/light modes. Add custom `:focus-visible` to standard stylesheets using design tokens. Add `aria-expanded` toggles dynamically in navigation scripts, and bind global 'Escape' keypress handlers to safely dismiss open elements and restore focus.
