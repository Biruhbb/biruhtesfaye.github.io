## 2026-07-24 - Dynamic Mobile Navigation Accessibility injection
**Learning:** In purely static, multi-page portfolios (lacking templating engines), modifying accessibility attributes in every single HTML file is highly error-prone and scales poorly. Instead, initializing and managing ARIA states (`aria-expanded`, `aria-controls`, and `aria-hidden` on nested decorative spans) dynamically via a single shared JavaScript bundle (`js/main.js`) ensures consistent accessibility compliance, keyboard focus restoration, and Escape-key closure across all pages with zero duplicate markup.
**Action:** Use centralized, client-side progressive enhancement scripts to inject and manage interactive ARIA structures dynamically in static HTML portfolios rather than modifying individual HTML files.
