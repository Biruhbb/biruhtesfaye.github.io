## 2025-07-20 - [Accessible Dark-Themed Mobile Nav Menu and Keyboard Focus]
**Learning:** Dark-themed websites can easily hide default browser focus indicators, compromising keyboard accessibility. Explicit `:focus-visible` styles using theme colors preserve clean visual aesthetics for mouse users while ensuring keyboard-only users can navigate confidently. Additionally, hidden elements (like mobile nav toggle spans and unicode contact icons) should be visually hidden from screen readers using `aria-hidden="true"`, and state controls like `aria-expanded` must be dynamically synchronized.
**Action:** Always include a custom, high-contrast `:focus-visible` outline in CSS, pair dynamic toggles with dynamic `aria-expanded` and `Escape` key listeners, and hide decorative content from screen readers.
