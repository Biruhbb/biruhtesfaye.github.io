## 2026-06-29 - Global Focus Visible Ring Pattern for Dark Theme Portfolios
**Learning:** Dark-themed minimalist portfolio sites with reset styles often omit explicit keyboard focus indicators, rendering navigation invisible to keyboard-only and assistive technology users while default browser rings can blend into dark backgrounds or look jarring. Using `:focus-visible` with the design system's accent token (`var(--accent)`) and a 3px outline offset provides crisp, distinct keyboard focus indicators without disrupting pointer/mouse user click interactions.
**Action:** Always verify `:focus-visible` on interactive elements (`a`, `button`, form inputs) against dark backgrounds using the primary brand accent color and an outline-offset to maintain separation from element borders.
