## 2026-08-07 - Focus Visibility & Interactive Mobile Menu Accessibility
**Learning:** In customized dark-themed portfolios, relying on browser-default keyboard focus states results in virtually invisible focus indicators, severely impacting accessibility. Furthermore, interactive components like hidden mobile navigation menus or elements animated with opacity: 0 via IntersectionObserver can create invisible focus traps if keyboard focus enters them.
**Action:** Always provide explicit, high-contrast :focus-visible rules with comfortable offsets, dynamically manage ARIA attributes (like aria-expanded and aria-controls), support expected keyboard interactions (like Close-on-Escape with focus restoration), and intercept focusin events on scroll-animated containers to instantly force their visibility.
